How to Install Telugu Fonts in MS Word

A step-by-step guide for installing any Telugu font in Microsoft Word on Windows and Mac, with troubleshooting tips.

7 min read·September 4, 2026·By Akshay

Typing Telugu in Microsoft Word is easy once three things are in place: a Telugu font, a way to type Telugu characters, and the right font setting inside Word. This guide covers all three on Windows and Mac, plus the fixes for the most common problems.

Step 1 — Download a Telugu Font

Windows already includes Telugu fonts (Nirmala UI, and Gautami / Vani with Telugu language support), but for nicer documents download a free font from Google Fonts. Good choices for Word:

  • Mandali — designed for news text, very readable in paragraphs
  • Noto Sans Telugu — clean and complete, multiple weights
  • Tiro Telugu or Noto Serif Telugu — for formal, printed-looking documents
  • Ramabhadra — for bold headings

Step 2 — Install the Font

Windows 10 / 11

  1. Unzip the downloaded file
  2. Right-click the .ttf file → Install for all users (recommended — some apps only see fonts installed this way)

Mac

  1. Double-click the .ttf file
  2. Click Install Font in Font Book

Close and reopen Word afterwards so it picks up the new font.

Step 3 — Add a Way to Type Telugu

Windows

Settings → Time & Language → Language & region → Add a language → Telugu. Choose the Telugu Phonetic keyboard if you want to type in English sounds, or Telugu (INSCRIPT) if you learned typing on the standard Indian layout. Switch keyboards with Win + Space.

Mac

System Settings → Keyboard → Input Sources → + → Telugu → choose Telugu - QWERTY (phonetic) or the standard Telugu layout. Switch with Ctrl + Space.

No time to set anything up? Type in English on our Telugu typing tool and paste the result into Word.

Step 4 — Set the Font Correctly Inside Word

This is the step most people miss. Word treats Telugu as a complex script and keeps a separate font setting for it. If you only change the normal font box, Word may keep showing Telugu in Nirmala UI or Gautami.

  1. Select your Telugu text (or the whole document with Ctrl + A)
  2. Press Ctrl + D to open the Font dialog
  3. Under Complex scripts, choose your Telugu font and size
  4. Click Set As Default if you want every new document to use it
Good to know: If the "Complex scripts" section is missing from the Font dialog, go to File → Options → Language and add Telugu as an editing language, then restart Word.

Troubleshooting

Telugu shows as boxes

The selected font has no Telugu characters (for example Calibri or Times New Roman in the complex-script setting). Apply a Telugu font as described in Step 4.

Letters look broken or vowel signs appear separately

Usually the text was typed with a legacy font such as Anu, or copied from an old PDF. It isn't real Unicode Telugu. Retype it or convert it; see our Anu fonts guide.

The document looks different on another computer

The other computer doesn't have your font. Either install it there, or in Word go to File → Options → Save → Embed fonts in the file. Saving as PDF also locks the look in place.

The new font doesn't appear in Word

Restart Word. If it's still missing, reinstall the font with "Install for all users".

Frequently Asked Questions

Which Telugu font is best for MS Word documents?

For everyday documents, Mandali or Noto Sans Telugu. For formal letters and printed reports, Tiro Telugu or Noto Serif Telugu. Gautami and Nirmala UI are the safest if the file will be opened on many different Windows computers.

How do I type Telugu in Word without installing a keyboard?

Use our Telugu typing tool: type in English (for example "namaskaaram"), copy the Telugu output and paste it into Word.

Why does Word ignore the Telugu font I select?

Word uses a separate "Complex scripts" font for Telugu. Open the Font dialog with Ctrl+D and set your font there.
