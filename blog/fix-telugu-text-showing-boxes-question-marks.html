Fix Telugu Text Showing Boxes, ??? or Broken Letters

Every common cause of broken Telugu text — and the exact fix for Windows, Mac, Android, Word, Photoshop and websites.

8 min read·September 9, 2026·By Akshay

Telugu text showing up as empty boxes (□□□), question marks (???), English gibberish, or letters with vowel signs floating in the wrong place? Each symptom has a specific cause — and a specific fix. Find yours below.

Fix 1 — Empty Boxes (Tofu)

The boxes are called "tofu". Your text is fine, but the font in use can't draw Telugu.

  • Word / Excel: select the text, press Ctrl + D and choose a Telugu font (Nirmala UI, Gautami, Noto Sans Telugu) under Complex scripts.
  • Windows in general: add Telugu under Settings → Time & Language → Language & region; this installs the Telugu Supplemental Fonts.
  • Website: add a Telugu font to your CSS, for example font-family: 'Noto Sans Telugu', 'Nirmala UI', sans-serif;

Fix 2 — Question Marks (???)

The Telugu characters were lost when the file was saved in an encoding that can't hold them (such as ANSI or Latin-1). The question marks are the damage — the original letters are gone from that copy.

  • Save text files as UTF-8 (Notepad: File → Save As → Encoding: UTF-8).
  • In Excel CSV exports, choose CSV UTF-8.
  • For databases, use utf8mb4 (MySQL) for the table and connection.
  • For web pages, include <meta charset="UTF-8">.

You'll need to go back to an earlier copy of the text; the question marks can't be converted back.

Fix 3 — English Gibberish

If Telugu turns into random English letters and symbols when you change the font or paste it somewhere, it was typed with a legacy font such as Anu. It was never real Telugu text. Convert it with a tool made for that font family, or retype it in Unicode. Our Anu fonts guide explains the options.

Fix 4 — Broken Vowel Signs and Conjuncts

Telugu needs "shaping" — software has to join consonants, vowel signs and subscripts. If you see క and ి side by side instead of కి, the app isn't shaping the text.

  • Photoshop / Illustrator: switch the paragraph to the World-Ready (South Asian) composer.
  • Old software (PageMaker, old CorelDRAW versions): these don't support Unicode Telugu shaping — use a newer app.
  • Font problem: a few fonts that claim Telugu support are incomplete. Try Noto Sans Telugu to confirm.

Fix 5 — Broken Only on Other People's Devices

  • Very old Android phones or feature phones may lack full Telugu support — nothing you can fix from your side except sending an image.
  • Documents: embed fonts (Word: File → Options → Save → Embed fonts in the file) or send a PDF.
  • Stylised "fancy" Unicode: decorative symbols from some fancy-text sites don't exist in every phone's fonts. Stick to plain Telugu text plus common symbols.

Frequently Asked Questions

Why does Telugu show as boxes on my computer?

The font being used has no Telugu glyphs. Switch to a Telugu font such as Nirmala UI, Gautami or Noto Sans Telugu, or add Telugu as a language in Windows settings.

Can I recover Telugu text that became ??? question marks?

No — the characters were replaced when the file was saved in a non-Unicode encoding. Go back to an earlier copy and save it as UTF-8.

Why does my Telugu turn into English letters when I change the font?

It was typed with a legacy (non-Unicode) font such as Anu. Convert it with a converter for that font family or retype it in Unicode.
